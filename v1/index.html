The foundation

What are nodes?

A blockchain node is a computer that runs blockchain software and keeps the network alive. Nodes require collateral to operate — and that collateral is what your NFT represents a share of. Its value can increase or decrease over time.

Store

Nodes hold a full copy of the ledger, keeping the blockchain's history safe and decentralized.

Verify

Every transaction is independently checked against the network's rules — no trust required.

Broadcast

Verified data is relayed peer-to-peer across the globe, keeping every participant in sync.

Each NFT = an equal share of the node collateral. The collateral backs real operating nodes, and its value can go up or down with the market.

The lifecycle

How it works

  1. 01

    Mint on OpenSea

    Mint your Node NFT from the official collection. Every NFT is identical in value and representation — no rarity games, no gas wars over traits.

  2. 02

    Collateral is pooled

    Mint proceeds form the node collateral that puts real nodes to work. Your NFT represents an equal share of that underlying collateral.

  3. 03

    Quarterly review

    Each quarter, the node collateral is reviewed to determine whether it should be increased for the following quarter. Every 4% resale fee collected along the way is added to the pool.

  4. 04

    Burn or buyback

    If the Legion determines the NFTs have increased sufficiently in value, a burn or buyback mechanism may be activated, minus 10% collateral.

Questions

FAQ

What are Nodes?

A blockchain node is a computer or device that runs blockchain software and helps store, verify, and broadcast data across the network. Nodes require collateral to operate, with each NFT representing an equal share of the underlying node collateral, whose value can increase or decrease over time.

What are the OpenSea fees?
  • 10% mint fee per NFT goes to OpenSea.
  • 4% enforced creator resale fee is added to the node collateral.
  • 1% resale fee to assist with network fees.
How do node rewards work?

Each quarter, the node collateral will be reviewed to determine whether it should be increased for the following quarter. If the Legion determines that the NFTs have increased sufficiently in value, a burn or buyback mechanism may be activated, minus 10% collateral.

Where can I track my node?

Once the mint has completed and the project is live, node status will be added to the website and Discord, allowing the Legion to track the status of the node NFTs.

What about artwork & rarity?

Each Node NFT is equal in value and representation. Any changes to the artwork, including design and associated costs, can be discussed at a later date if the Legion decides to pursue them.
