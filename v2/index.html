FAQ

What are Nodes?

A blockchain node is a computer or device that runs blockchain software and helps store, verify, and broadcast data across the network. Nodes require collateral to operate, with each NFT representing an equal share of the underlying node collateral, whose value can increase or decrease over time.

What are the OpenSea fees?
  • 10% mint fee per NFT goes to OpenSea.
  • 4% enforced creator resale fee is added to the node collateral.
  • 1% resale fee to assist with network fees.
How do node rewards work?

Each quarter, the node collateral will be reviewed to determine whether it should be increased for the following quarter. If the Legion determines that the NFTs have increased sufficiently in value, a burn or buyback mechanism may be activated, minus 10% collateral.

Where can I track my node?

Once the mint has completed and the project is live, node status will be added to the website and Discord, allowing the Legion to track the status of the node NFTs.

What about artwork & rarity?

Each Node NFT is equal in value and representation. Any changes to the artwork, including design and associated costs, can be discussed at a later date if the Legion decides to pursue them.
